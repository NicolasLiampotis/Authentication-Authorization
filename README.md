# Authentication-Authorization

This repository contains the Authentication and Authorisation documentation for the ECHOES project.

ECHOES is setting up the European Collaborative Cloud for Cultural Heritage (ECCCH), a shared platform for heritage professionals, researchers, data, metadata, tools, applications and collaborative workflows. Within this wider cloud ecosystem, the Authentication and Authorisation component supports secure and interoperable access for ECHOES services, sister projects and participating communities.

## Relationship with the ECCCH architecture

In the ECCCH cloud ecosystem, this repository corresponds to the Authentication & Authorisation component. It describes how login, identity federation, group and role information, token validation and AAI interoperability support the Single Entry Point, protected services, APIs and cross-project access scenarios.
